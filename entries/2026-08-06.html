PDF Text Extraction → Chunking → Embedding

2026-08-06

Progress today

  • Can now extract text information from PDF documents.
  • Implemented chunking in two ways: semantic chunking and word-count (fixed-size) chunking.
  • Passed the chunked text into an embedding model to complete the embedding step, so the extraction → chunking → embedding pipeline is now in place.

Open question

Should I keep investing time in learning and implementing different RAG techniques — for example, GraphRAG — on top of the current pipeline?

Current pipeline is a straightforward vector RAG foundation: PDF → text → semantic/word-count chunks → embeddings. The question is whether the next step should be retrieval strategy improvements, knowledge-graph-based retrieval (GraphRAG), or something else entirely.

Next steps

  • Compare retrieval quality between semantic and word-count chunking on a small test set before choosing the default.
  • Decide whether GraphRAG (or another RAG variant) is worth exploring, based on the questions the pipeline needs to answer.
